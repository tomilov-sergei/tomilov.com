Find a Vibe Spot concept by prosku.a A two-dimensional panel with gradations. A similar solution exists in iOS in photo editing mode. A cool interface solution. Unlike one-dimensional sliders, there is great variability here. And it is quite intuitive. Some values cannot be polar to each other, but can still be in a common pool of options In 2022 I came up with such a way to set the mood of music, "Mood Tuner". I came to the solution through thinking that for a music app you want to transmit vibe at the interface level. I wanted UI elements to resemble interfaces of music devices. Back then I did not have enough to polish it to a state where the result was clear. In Apple's version and prosku.a's version, they did polish it ✨
