Transit updated This is probably the best app for moving around cities. I remember when in the first versions there were so few cities, I even went somewhere on vacation specifically to feel Transit An app for optimizing movement around the city. Note that in the name of this optimization the app uses large type - to read while walking, running, standing in a tram. Contrasts - 🤌 Pleasant work with color tokens. I like that they did not fall into "digital" screaming shades, while everything looks saturated enough. Separately, I want to draw attention to the interface behavior - they use the pull gesture for canceling and returning to the home screen. Looks like this is a frequent scenario that they optimized. Settings, where a social profile appeared - well, understandable 🥰. Taking note of how you can draw attention instead of meaningless red dots and instead of annoying tips. Beauty: 10 out of 10
