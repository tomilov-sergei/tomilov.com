Caught! I was a little afraid of this. I knew it would happen. I did nothing to prevent it. Lived this life as it is. On November 28, on an ordinary sunny day, I, as usual, stumbled upon an interesting thing. The image of the interesting thing went into the Screenshots folder. And today, a month later, its turn came. And I do not remember the context 😿 Good thing the thing is familiar: it is another layout of elements in the sheet when creating stories on Instagram. Pay attention: everything fits on one screen, the texts are set neatly in lowercase with capitals and in the branded font. It should be more usable. Rolling to prod 100%? But in prod everything is still the old way. A huge sheet, labels in uppercase. Where did I get the compact screenshot from? If only the operating system remembered the parent object from which the screenshot was taken. In this menu that opens on swipe up, it could neatly write: Screenshot taken from app N, version x.y, state: z. A kind of pro version of the operating system for professionals, which tracks context and environment, and does not only work with input-output. Enough living in a paradigm created well, almost a hundred years ago! It is time to create a new one. We have everything for this. In a titanium body, in black, and consuming 100 ml of water for every query
