In principle, playable. The internal image resolution is not high; video in TG will not convey the 1:1 feeling. It looks more than decent. It looks incredible. What to compare with? Nothing as technologically advanced has ever been made on a mobile phone before. And here without reservations: an open world, not 2x2 rooms in Diablo Immortal. You can feel that this is a port because of the controls. The sticks behave like on a console. On mobile it needs to be somewhat different. For example, as in Honkai or WoD. Where there is a large gesture zone: move around the screen with the left finger and run, aim with the right. Conceptually it is done the same here, but in implementation it is uncomfortable Check out the graphic code: these beautiful patterns on the screen are the virtual button layout. So elegant. For myself I understood: graphics are possible on mobile, but not needed. Gameplay is more important, and most importantly - respect for the user's time. The shorter the loads, the faster the scenario from tapping the game icon to actual gameplay, the better
